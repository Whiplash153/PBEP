Sandbox

Goal

This sandbox is a continuously evolving practice project used throughout the DevOps stage of PBEP. It serves as a safe environment for experimenting with Docker, Docker Compose, deployment, and CI/CD without affecting the main study projects.

What was done

The sandbox started as a simple FastAPI application containerized with Docker. During the following topics, it will be gradually expanded with Docker Compose, PostgreSQL, volumes, environment variables, reverse proxy, deployment configuration, and automation tools.

Notes

The sandbox is not tied to a single task. It is a long-term training project that grows together with the DevOps stage and demonstrates how a backend application evolves into a complete production-ready environment.
