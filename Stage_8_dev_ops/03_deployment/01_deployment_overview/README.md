# Deployment Overview

## Goal

Learn how to deploy a backend application from a local machine to a remote server.

## What was learned

- What deployment is.
- What a VPS is.
- Why Docker is useful for deployment.
- The difference between VPS and managed platforms like Render or Railway.
- That a deployed application runs exactly like it does locally, but on a remote Linux server.

## Key ideas

- Deployment is the process of publishing an application to a remote machine.
- A VPS is a rented Linux server with full control over the environment.
- Docker allows the application to run the same way on both the local computer and the server.
- Docker Compose starts all required services (backend, database, etc.) with a single command.
- Managed platforms automate many server tasks, while a VPS gives full control.

## Result

Prepared to deploy a Dockerized FastAPI application to a real VPS in the next practical task.
