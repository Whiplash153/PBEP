# Task: Unique Delivery Addresses

## Condition
The courier company received a list of delivery addresses for the day.  
Some addresses are duplicated because different customers ordered to the same location.  
You need to determine how many **unique addresses** need to be visited.

## Solution
We stored all delivery addresses in a list and used a **set** to remove duplicates.  
Then we printed all unique addresses and displayed their total count.  

**Tools used:** list, set, for-loop, len(), print.
