# Task: Personalized Greeting

## Condition
The company is developing an automatic greeting system for employees.  
The program should display a personal greeting if a name is provided and a standard greeting if no name is passed.

## Solution
We created a function `greet(name="colleague")` that takes an argument `name` with a default value.  
When called with a name, it prints a personalized greeting; otherwise, it uses the default one.  

**Tools used:** functions, arguments, default values, print.
