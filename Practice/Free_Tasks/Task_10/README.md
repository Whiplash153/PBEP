# Task: Greeting Function with Argument

## Condition
Create a function that displays a personalized welcome message for the user.  
The function should accept one argument — the user's name — and print a greeting message.

## Solution
We defined a function `greet(name)` that takes a single parameter `name`.  
Using an **f-string**, the function prints a formatted welcome message.  
The call is wrapped in the `if __name__ == "__main__":` block,  
which ensures correct execution when the file is run directly.

**Tools used:** functions, parameters, f-strings, conditional main block.
