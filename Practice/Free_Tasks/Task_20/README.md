# Task: List Processing Exercises

This set of mini-exercises focuses on practicing list iteration and simple data processing using loops.

The tasks include:
- calculating the sum of numeric values in a list;
- finding the maximum number in a list by iterating through all elements;
- filtering elements based on a condition and printing only values that meet the requirement;
- creating a new list by transforming each element of an existing list.

Tools used: lists, `for` loops, variable accumulation, conditional checks, and creating new lists.
