# Task: Inventory Management System

This task implements a simple inventory system using a class and several helper functions.

The program includes:
- a `StoreItem` class for representing a product with its name, price, and quantity;
- methods for calculating item cost, increasing quantity, and removing items with error handling;
- a function that converts a dictionary of raw inventory data into a list of objects;
- a function that calculates the total value of all items in the inventory;
- a function that processes a sale request, updates the item quantity, and returns the sale amount or `None` when the item cannot be sold.

Tools used: classes, object methods, loops, dictionaries, lists, basic error handling, and value returning.
