# Task: Mini Drink Warehouse

This task implements a simplified warehouse system using dictionaries only.  
It includes two functions:

- A function that calculates the total cost of all drinks based on their price and quantity.
- A function that processes a sale request, checks availability, updates the quantity, and returns the cost of the sale or `None` when the sale cannot be completed.

Tools used: dictionaries, loops, conditional checks, basic arithmetic, and returning values.
