# Task: Notes Journal

Write a program that:
1. Asks the user to input a text note;
2. Saves the note to a file `notes.txt` (adding to the end, not overwriting);
3. Reads and displays all saved notes line by line with numbering;
4. If the file is empty or does not exist, prints a message "No notes yet."

Tools used: file operations (`open`, `with`), loops, conditionals, `enumerate()`, `encoding="utf-8"`.
