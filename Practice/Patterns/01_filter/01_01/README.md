# Filter → Transform → Collect — Level 1.1

## Goal
To master the base mechanics of the pattern on simple, flat data structures such as lists of numbers and lists of strings. The goal of this level is to build stable muscle memory for separating filtering, transformation, and collection into clear, independent steps.

## What was done
- Applied the pattern on flat lists without nested structures.
- Practiced explicit separation of Filter and Transform stages using two independent loops.
- Solved five variations of increasing difficulty, each requiring filtering by a condition, transforming selected items, and collecting results into a new list.
- Worked with strings and numbers, practicing conditions, string methods, and basic data formatting.
- Reinforced the principle of producing a new output structure without mutating the input data.

## Notes
- Each stage of the pattern must remain isolated: filtering decisions should not mix with transformation logic.
- Input data should always remain unchanged; only new collections are created.
- The result structure may vary (strings, dictionaries, numbers), but the pattern flow stays the same.
- Mastery of Level 1.1 is a prerequisite for moving to Level 1.2, where the same pattern is applied to lists of dictionaries.
