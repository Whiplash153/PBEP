## Goal
Practice applying the Filter → Transform → Collect pattern to nested data structures.
Focus on extracting nested fields and using aliases before conditions.

## What was done
Filtered collections based on multiple conditions using alias variables.
Transformed filtered data into new structures with derived values while keeping input data immutable.

## Notes
All conditions were built only on alias variables, not direct nested access.
Main difficulty of this level is discipline: extract first, then decide.
