# Filter → Transform → Collect — Level 1.2

## Goal
To apply the pattern to list-of-dictionaries structures. The focus of this level is learning how to access fields inside objects, filter by multiple keys, and construct new dictionaries as output structures.

## What was done
- Practiced filtering full dictionary objects based on multiple conditions.
- Extracted data from dictionary fields and performed transformations (renaming keys, modifying values, computing new fields).
- Built new dictionaries without mutating the original input data.
- Solved three training tasks and five exam tasks with increasing complexity.
- Formed stable muscle memory for handling typical backend data formats such as JSON-like lists of objects.

## Notes
- Filtering should always operate on whole objects, not isolated fields.
- Transform must create a new dictionary each time, keeping the original dataset untouched.
- This level is a direct preparation for Level 1.3 and further for Level 2 where nested structures appear.
