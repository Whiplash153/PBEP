# Pattern 01 — Filter → Transform → Collect  
## Level 1.3

This module completes Level 1 of the FTC pattern by applying the algorithm to mixed data structures.  
The tasks introduce nested dictionaries, lists inside dictionaries, and combined conditions.

### Goal
To practice the FTC pattern on real-world–like data formats:
- filtering by multiple conditions,
- extracting values from nested structures,
- transforming data into a new shape,
- building a clean result without mutating the input.

### What was done
- Worked with dictionary → list → dictionary structures.
- Applied multi-step filtering logic based on nested numerical values.
- Computed derived values (averages, differences, ranks, categories).
- Used conditional branches to classify elements.
- Produced new dictionaries representing transformed results.
- Organized the process into two-pass FTC logic:  
  1) filtering items,  
  2) transforming and collecting them.

### Key concepts
- Accessing nested data through clear variable aliases inside loops.
- Keeping transformation separate from filtering.
- Using clean conditional logic instead of inline complexity.
- Preparing data for later levels with deeper nesting.

### Outcome
Level 1.3 of the FTC pattern is completed.  
The next stage is Level 2, where the same algorithm is applied to full nested JSON structures.
