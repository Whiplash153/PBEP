# Task 3: Params and Body

## Goal
Understand how to separate the route part of a REST path, extract query parameters, and handle the request body.

## What was done
The program takes a method, path, and body, prints the incoming request, splits the path to isolate the route portion, extracts query parameters if present, and outputs the body as received.  
Only basic string operations were used, repeating the logic practiced in previous steps.

## Notes
This task focuses on recognizing the structure of a REST request rather than modifying resources.  
Route and query parts are processed independently.  
The solution avoids new concepts and follows only the methods learned in steps 1–3.
