# REST API – Mini Resource Case

## Goal
Implement a minimal REST-like resource handler to practice CRUD operations and HTTP status code logic without using any frameworks.

## What was done
Built an in-memory storage layer, a request handler that processes REST methods and paths, and a demo client that simulates requests.
Implemented GET, POST, PUT, and DELETE behavior for a single resource while strictly following REST status code rules.

## Notes
REST logic was separated from storage logic to mirror real backend architecture.
HTTP status codes reflect operation outcomes rather than request intent or implementation details.
