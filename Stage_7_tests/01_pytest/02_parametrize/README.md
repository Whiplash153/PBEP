## Goal  
Learn how to use pytest parametrize to test multiple input cases within a single test function.

## What was done  
Implemented functions and created parameterized tests using pytest.mark.parametrize. Verified multiple input-output combinations in a single test. Ensured correct test discovery and execution.

## Notes  
Parametrize reduces code duplication and improves test scalability. Each set of parameters is treated as a separate test case. Proper naming of modules is important to avoid import conflicts.
