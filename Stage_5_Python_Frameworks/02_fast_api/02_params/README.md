# FastAPI Query and Path Parameters

## Goal
Learn how to use path and query parameters in FastAPI endpoints.

## What was done
Created endpoints with path parameters and combined them with query parameters.  
Implemented dynamic routes and default query values.  
Tested endpoints through browser and Swagger UI.

## Notes
Path parameters define resource identity, while query parameters modify the request.  
FastAPI automatically validates parameter types and returns errors for invalid input.  
Default values make query parameters optional.
