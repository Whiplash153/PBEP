# REST API — Resources and Endpoints

## Goal
To understand the core concepts of REST: resources, collections, elements, and how endpoints represent them through paths and HTTP methods.

## What was done
This task introduced the idea of a resource as a data entity and showed how collections and individual elements are represented. The difference between path-based endpoints and action-based paths was demonstrated, following REST conventions. A simplified client–server interaction was modeled to show how a method and a path together define an operation in REST.

## Notes
REST is a convention layered on top of HTTP, not a part of the protocol.  
Paths represent resources, while methods define actions.  
Correct endpoint structure is essential for predictable and consistent API design.
