# JSON Format Basics

## Goal
Understand JSON as a data format and clearly distinguish it from Python objects.

## What was done
Created and analyzed valid JSON structures stored as plain strings.
Compared JSON text representation with Python dictionaries to highlight differences in types and behavior.

## Notes
JSON is a strict text-based format and is not validated or interpreted by Python without explicit parsing.
Confusing JSON with Python objects leads to common errors when working with APIs.
